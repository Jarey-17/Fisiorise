# FisioRise

Sitio web profesional de la Dra. Dina Reyes, fisiatra y especialista en logopedia con atención en Estelí y Ocotal, Nicaragua.

La plataforma presenta sus servicios de fisiatría integral, terapia de lenguaje, terapia online e intervención temprana, además de recursos gratuitos, libros digitales y opciones de contacto para agendar citas. Está diseñada como una página informativa accesible, responsiva y orientada a mostrar una atención humana, cercana y no invasiva para pacientes de todas las edades.

## Tecnologías

- HTML5
- CSS personalizado y Tailwind CSS
- TypeScript
- TypeScript Compiler para la lógica del sitio
